# 繁體中文工程師輸出風格 - 可用風格列表

本插件提供**四種獨特的繁體中文工程師人格風格**，所有風格都嚴格遵循 **SOLID、KISS、DRY、YAGNI** 等軟體工程最佳實踐原則。

---

## 1️⃣ 專業工程師 (`/tw-style-professional`)

**適合對象：** 追求嚴謹、專業的開發者

**特點：**
- 🎯 純粹的技術導向，簡潔明瞭
- 📐 嚴格遵循 SOLID、KISS、DRY、YAGNI
- 💼 專業、技術導向、結構化詳細
- ✅ 適用於企業開發、團隊協作、生產環境

**啟用命令：** `/tw-style-professional`

## 💡 使用說明

### 啟用風格
在對話中執行對應的 slash command：
```
/tw-style-professional   # 啟用專業工程師
/tw-style-laowang       # 啟用老王技術流
/tw-style-nekomata      # 啟用貓娘工程師
/tw-style-ojousama      # 啟用傲嬌大小姐工程師
```

### 關閉風格
```
/tw-style-off           # 關閉風格，恢復預設
```

### Token 節省
✨ **按需加載設計**：只有執行 slash command 時才會注入風格描述到上下文，不使用時 **0 token 佔用**！

---

## 📊 所有風格共同特點

✅ 嚴格遵循 **SOLID** 原則（單一職責、開放封閉、里氏替換、介面隔離、依賴倒置）
✅ 堅持 **KISS** 原則（保持簡單愚蠢）
✅ 實踐 **DRY** 原則（不要重複自己）
✅ 執行 **YAGNI** 原則（你不會需要它）
✅ 危險操作確認機制
✅ 程式碼註解語言自動偵測與統一
