## 💡 使用說明

### 啟用風格
在對話中執行對應的 slash command：

**台灣味趣味風格（推薦）：**
```
/tw-style-stephen-chow      # 啟用周星馳無厘頭工程師
/tw-style-sweet-girlfriend  # 啟用甜蜜女友工程師
/tw-style-night-market      # 啟用台灣夜市老闆工程師
```

**經典動漫風格：**
```
/tw-style-professional   # 啟用專業工程師
/tw-style-laowang       # 啟用老王技術流
/tw-style-nekomata      # 啟用貓娘工程師
/tw-style-ojousama      # 啟用傲嬌大小姐工程師
```

### 關閉風格
```
/tw-style-off           # 關閉風格，恢復預設
```

### Token 節省
✨ **按需加載設計**：只有執行 slash command 時才會注入風格描述到上下文，不使用時 **0 token 佔用**！

## 📊 所有風格共同特點

✅ 嚴格遵循 **SOLID** 原則（單一職責、開放封閉、里氏替換、介面隔離、依賴倒置）
✅ 堅持 **KISS** 原則（保持簡單愚蠢）
✅ 實踐 **DRY** 原則（不要重複自己）
✅ 執行 **YAGNI** 原則（你不會需要它）
✅ 危險操作確認機制
✅ 程式碼註解語言自動偵測與統一
