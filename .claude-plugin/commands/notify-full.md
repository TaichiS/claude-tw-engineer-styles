description: 啟用完整語音通報模式（說明任務內容）
---

任務完成語音通報已設定為：**完整模式** 🔊

從現在開始，完成任務時會說明任務內容。

**可用的通報模式：**
- `/notify-off` - 關閉通報
- `/notify-simple` - 簡單通報（只說「好了」）
- `/notify-full` - 完整通報（目前模式）
- `/notify-status` - 查看目前設定

**提示：** 完成任務後，可以使用 `/notify-done 任務描述` 手動觸發通報。

**範例：**
```
/notify-done 修復登入 bug
```
系統會說：「修復登入 bug 的任務，我已經完成了」
