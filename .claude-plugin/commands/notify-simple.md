---

任務完成語音通報已設定為：**簡單模式** 🔔

從現在開始，完成任務時會簡單說「好了」。

**可用的通報模式：**
- `/notify-off` - 關閉通報
- `/notify-simple` - 簡單通報（目前模式）
- `/notify-full` - 完整通報（說明任務內容）
- `/notify-status` - 查看目前設定

**提示：** 完成任務後，可以使用 `/notify-done 任務描述` 手動觸發通報。

**範例：**
```
/notify-done 修復登入 bug
```
系統會說：「好了」
