# 任務完成語音通報設定

**目前模式：** 請執行此命令後查看系統訊息

**可用的通報模式：**
- `/notify-off` - 🔇 關閉通報
- `/notify-simple` - 🔔 簡單通報（只說「好了」）
- `/notify-full` - 🔊 完整通報（說明任務內容）

**使用方式：**
1. 選擇一個通報模式（執行對應的命令）
2. 完成任務後，執行 `/notify-done 任務描述` 來觸發通報

**範例：**
```bash
# 設定為完整通報模式
/notify-full

# 完成任務後觸發通報
/notify-done 重構使用者認證模組
```

系統會說：「重構使用者認證模組的任務，我已經完成了」
